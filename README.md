# product-answer-checks

What it costs to check an AI shopping answer against its product listing before it is shown, and what each
check catches. Test 1 compares four arms on product questions answered by two hosted models, with French and
English listings. Method in [`docs/METHOD.md`](docs/METHOD.md). No results yet.

The claim check under test is [`legal-rag-verifier`](https://github.com/azterizm/legal-rag-verifier), which reads
prices, dates and units in French and English.
